# «Звёзды охуели» — бесплатная автопубликация гороскопов ВК

Программа готовит 12 уникально-комбинируемых шуточных гороскопов и ставит их в отложенные записи сообщества ВК — по одному для каждого знака, ориентировочно с 09:00 до 20:00 по московскому времени.

## Бесплатная схема

- GitHub — хранение кода.
- GitHub Actions — ежедневный запуск (в пределах бесплатной квоты GitHub).
- VK API — публикация.
- Генерация — локальные шаблоны и комбинации фраз; платная нейросеть и OpenAI API не используются.

GitHub Actions для приватного репозитория имеет лимиты бесплатных минут. Для короткого ежедневного запуска Python обычно хватает бесплатной квоты, но GitHub может изменить условия. В публичном репозитории стандартные GitHub-hosted runners доступны бесплатно, однако публичность кода означает, что исходники видны всем. Секреты всё равно хранятся в GitHub Secrets.

## Настройка

В репозитории открой Settings → Secrets and variables → Actions → New repository secret и добавь:

- `VK_ACCESS_TOKEN` — ключ сообщества ВК (никому не показывай).
- `VK_GROUP_ID` — `243138653`.

Затем открой Settings → Secrets and variables → Actions → Variables и добавь:
- `PUBLISH_ENABLED` = `true` — включать только после проверки.

Если переменная не задана или не равна `true`, скрипт ничего не публикует.

## Расписание

Workflow запускается ежедневно в 06:00 UTC (09:00 по Москве зимой) и вызывает `main.py`. Скрипт создаёт отложенные публикации на 09:00–20:00 по московскому времени. GitHub Actions может запускаться с задержкой; расписание не является гарантией запуска ровно в минуту.

## Важно

- Никаких Render-сервисов и платных API в этой схеме нет.
- Не загружай токен ВК в файлы репозитория, Issues или сообщения.
- Перед включением публикаций нужно проверить, что ключ ВК действительно имеет доступ к `wall.post` и `wall.get`/стене. Если ВК отклонит запрос, нужно будет скорректировать тип ключа или авторизацию.
- Скрипт публикует отложенные записи; повторный ручной запуск может создать дополнительные записи. Не нажимай Run workflow повторно без проверки стены сообщества.
- Тексты шаблонные и развлекательные, а не нейросетевые.
