# «Звёзды охуели» — автопубликация коротких гороскопов ВК

Бот готовит до 12 записей в день, по одной на каждый знак зодиака. Работает без платного ИИ.

## Формат поста

- Одно короткое предложение с прогнозом для знака и датой.
- Ровно три коротких хэштега: знак зодиака, #гороскоп и #зодиак.
- Никаких цифр, подчёркиваний или случайных кодов в хэштегах.
- Без длинных вступлений и дополнительных предложений.

Пример:

🔮 Овен на 13.11.2026: закрой одну важную задачу — лишний пиздец сегодня не заказывали.

#Овен #гороскоп #зодиак

## Защита от повторов

- Перед созданием новых записей бот читает стену ВК через wall.get: отложенные записи (filter=postponed) и уже опубликованные (filter=owner).
- Учитывает старый и новый формат постов; не создаёт второй гороскоп для того же знака и даты.
- Если стену ВК прочитать не удалось или проверка неполная, публикации останавливаются, а не создаются вслепую.
- Стабильный параметр guid у wall.post остаётся дополнительной защитой.
- Тексты имеют 400 различных комбинаций для одного знака на 400 последовательных дней; дата в предложении обеспечивает различимость разных дней.
- Автоматические тесты проверяют длину, одно предложение, три хэштега, отсутствие цифр и распознавание дублей.
- Уже созданные дубли не удаляются автоматически.

## Расписание

GitHub Actions запускается по cron 45 4 * * * — это 04:45 UTC, 07:45 по Москве.
Бот планирует до 12 записей с 08:00 до 11:40 по Москве через каждые 20 минут.
Если GitHub Actions задерживается, первая запись сдвигается вперёд, как и раньше.
Расписание не менялось.

## Настройка и безопасность

- VK_ACCESS_TOKEN — секрет с доступом к чтению стены и созданию постов.
- VK_GROUP_ID — идентификатор сообщества 243138653 (есть значение по умолчанию).
- В GitHub workflow переменная PUBLISH_ENABLED установлена в true.
- PREVIEW_ONLY=true python main.py выводит предпросмотр без запросов в ВК.
- python -m unittest -v test_main.py запускает тесты без публикаций.
- В render.yaml по умолчанию PUBLISH_ENABLED=false; при включении другого сервиса ему нужна та же проверка дублей.

Не передавайте токены в чат и не сохраняйте их в коде.
