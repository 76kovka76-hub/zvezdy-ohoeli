# «Звёзды охуели» — автопубликация гороскопов ВК

Скрипт раз в сутки генерирует 12 юмористических гороскопов и ставит их в отложенные записи сообщества ВК: по одному посту в час с 09:00 до 20:00 по московскому времени.

## Переменные окружения

- `VK_ACCESS_TOKEN` — ключ доступа сообщества ВК с разрешением «Стена».
- `VK_GROUP_ID` — ID сообщества без префикса club (сейчас `243138653`).
- `OPENAI_API_KEY` — отдельный API-ключ OpenAI. Подписка ChatGPT не включает API-кредиты; использование API оплачивается отдельно.
- `PUBLISH_ENABLED` — по умолчанию `false`. Переключать в `true` только после проверки всех настроек.
- `OPENAI_MODEL` — модель генерации (по умолчанию `gpt-4.1-mini`).
- `VK_API_VERSION` — версия VK API.

## Безопасный запуск

1. Добавить секреты только в Environment Variables Render. Не помещать их в GitHub и не отправлять в чат.
2. Первый запуск оставить с `PUBLISH_ENABLED=false`: он ничего не публикует.
3. Проверить ключи и настройки, затем включить публикацию.

## Расписание

Render Cron использует UTC. Задание запускается ежедневно в 06:00 UTC (09:00 по Москве). Скрипт ставит записи на следующий календарный день: 09:00, 10:00, …, 20:00 по Москве.

## Важно

- Создание и работа Render Cron Job могут быть платными. До создания сервиса нужно проверить стоимость и подтвердить её.
- Генерация через OpenAI API оплачивается отдельно; подписка ChatGPT не включает API-кредиты.
- Публикация зависит от разрешений ключа ВК и доступности API.
- Не запускать повторно вручную после успешного запуска без проверки отложенных записей.
